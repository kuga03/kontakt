Большие карты режимов (CTF / BOMB / KOTH)
=========================================

Файлы
-----
bomb.json  — «Заводская застава» 4400x900, тема zavod     (BOMB)
ctf.json   — «Три моста»        4400x900, тема krisha    (CTF)
koth.json  — «Пыльный перекрёсток» 4800x900, тема pustinya (KOTH)

Формат — level-objects (как в редакторе уровней):
  { type: 'ground'|'platform'|'cover'|'building'|'wall'|'spawn',
    x, y, w, h, texKey?, spawnType? }
  y — ЦЕНТР объекта (top = y - h/2). У spawn дополнительно spawnType:
  player/team/enemy (старт бойцов) и ammo/medkit/armor/frag/smoke (предметы).
  Спавны player/team/enemy в режимах не используются (боты встают сами),
  но player-спавн берётся для игрока. Предметы спавнятся всегда.

Как подключено
--------------
js/scenes/BootScene.js  — this.load.json('modeMap_BOMB'/'modeMap_CTF'/'modeMap_KOTH', maps/*.json)
js/data/modeMaps.js     — getModeMap(scene, mode): файл из кэша, иначе null
js/scenes/GameScene.js  — в CTF/BOMB/KOTH this.campaignLevel = getModeMap(...):
                          карта строится той же веткой, что уровень кампании
                          (ширина/тема/геометрия/предметы берутся из файла,
                          процедурные арены НЕ строятся).
Нет файла — режимы играют на старых процедурных аренах (без ошибок).

Правила дизайна (проверяются валидатором)
-----------------------------------------
- минимум 3 независимых пути от базы до базы: низ (земля), середина
  (платформы с верхом 700), верх (580; у CTF ещё насесты 460);
- шаг ступени ≤60 (носильщик проходит), одиночный прыжок ~78px,
  двойной ~141px, горизонтальный радиус ~144px → зазоры ≤120–144;
- тело k=2.2 (66x123): зазоры по низу ≥80, под нависанием просвет ≥130,
  «трещины» 29–50px запрещены; верхние платформы тонкие (h8), чтобы
  влезть и в просвет (130), и в прыжок (140);
- версии карт: поле mapVer (сейчас 7) — старые импорты в localStorage
  без версии игнорируются, берите свежие maps/import_*.txt;
- базы/точки захвата чистые: ±140 от базы, KOTH-точки достижимы,
  платформа B имеет верх ровно mapHeight - 140 (760 при высоте 900);
- ground всегда один: { x: W/2, y: H-25, w: W, h: 50 } → верх 850.

Импорт своей карты без правки файла
-----------------------------------
Открыть maps/import_<mode>.txt и вставить в консоль браузера (или сохранить
как закладку) — карта уходит в localStorage['sideShooterModeMaps'] и
перезагружает страницу. Сброс:
  localStorage.removeItem('sideShooterModeMaps');

Формат override — объект по режимам:
  { "CTF": {...level...}, "BOMB": {...level...}, "KOTH": {...level...} }
