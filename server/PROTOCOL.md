# Протокол сети КОНТАКТ v7 (классы/кик/зоны/нож/прокачка/овертайм)

Транспорт: WebSocket, адрес `ws://HOST:8081/net`, сообщения — JSON.
Комнаты: `GET /rooms` (или WS `list`) — список; `hello` с полем `room`
входит/создаёт комнату (без поля — `main` для LAN-совместимости).
Хост (первый в комнате) настраивает режим и места.

## Клиент → сервер

| Сообщение | Поля | Ответ |
|---|---|---|
| `hello` | `name` (до 16, уникально в комнате), `cls` (класс), `gear` ({cap,shoe,torso,pants,body} — надетое), `maxHp`/`maxArmor` (свой билд, коридоры 50–250/0–150), `room` (имя 1–24; нет — создаётся; пусто — `main`) | `welcome` (с именем комнаты) или `error` (полная/идёт/имя занято/Много комнат); в идущем матче то же имя = переподключение (старый сокет с тем же id гасится), новичок в первые 60с (не DUEL, есть место) = поздний вход |
| `list` | — (можно до hello) | `rooms` (список комнат) |
| `ping` | `n` (эхо) | `pong` |
| `setup` | `mode` (TDM/FFA/CTF/BOMB/KOTH/DUEL), `maxPlayers` (2–8; DUEL всегда 2), `timeLimit` (мин, 0 = без лимита, 1–30; по умолч. 5), `difficulty` (novice/experienced/veteran, по умолч. experienced), `botsOn` (добивать ли ботами до мест — видно всем, гости рисуют превью), только хост, до старта | рассылка `roominfo` |
| `ready` | `ready: true/false` | рассылка `players` |
| `team` | `team` (blue/red/auto), до старта | рассылка `players` (поле `wantTeam`) |
| `cls` | `cls` (Assault/Tank/Medic/Sniper), `gear` (скин этого класса), `maxHp`/`maxArmor`, до старта | рассылка `players` (поле `cls`) |
| `kick` | `id`, только хост, до старта | жертве `kicked`, всем рассылка `players` |
| `start` | `bots` (0–4, только хост; DUEL всегда 0; минимум: люди+боты ≥2; старт — только когда ВСЕ готовы) | рассылка `started` (включая ботов) или `error` (кого ждём) |
| `snap` | `x,y,vx,vy,hp,armor,aimX,aimY,weapon,crouch` + `taken` (своя стойкость 0.2–1), `maxHp`/`maxArmor`, `headY` (живая высота головы из рига — боты целят по факту; коридор ±120 от y) (макс. 20Гц, только в матче; телепорт >600px/с не двигает серверную позицию) | ретрансляция соседям |
| `hit` | `target` (id), `dmg` (1–150, база без зон; потолок — база ствола ×2.5, выше клампим), `weapon` (обязан существовать в справочнике, алиасы латиницы ок), `zone` (head/body/legs), `mult` (свой хедшот-множитель 1–2, применяется только в голову) | `damage` всем (при валидном: дистанция — min(1300, дальность+600), темп — по скорострельности ствола, стена между режет) |
| `melee` | `target` (id), `dmg` (1–150, потолок как в hit), `weapon` (обязан существовать; нож/катана/мачете — тело x1, дистанция 140, темп 4/с) | `damage` всем (при валидном: стена режет) |
| `fire` | `weapon` (обязан существовать, BOT-* ок), `x`, `y` (в границах арены), `angle`, `n` (пуль в очереди, 1–5) | ретрансляция соседям (мусор не relay'им; пустой магазин и окно перезарядки — дроп) |
| `reload` | `weapon` (имя ствола; сервер ставит `reloadingUntil = now + reloadTime` из справочника, 2000мс если нет; по истечении магазин полный; `fire` во время — дроп) | магазин сбрасывается в полный по истечении |
| `naded` | `type` (frag/smoke), `x`, `y` (рядом с телом, 150px), `angle` | ретрансляция (полёт считают все); бросок запоминается — без него `boom` отклоняется |
| `boom` | `type`, `x`, `y` (продолжение своего `naded`: тот же тип, окно запала frag 300–2000мс / smoke 200–1600мс, ≤800px от точки броска, ≤400px от кидавшего; стены режут по двум точкам; один boom на один naded) | frag: всем вспышка + урон по площади от сервера; smoke: только `smoke` остальным (без вспышки) |
| `smoke` | `x`, `y` | всем дым (визуал) |
| `kit` | `id` (`мойId:счётчик`), `type`, `x`, `y` | ретрансляция (id финал; при коллизии автору лично `kitfix` с новым id) |
| `kitwant` | `id` (дистанция до кита ≤250px — вакуум режем) | `kitok` всем, если свободен (кто первый) |

## Сервер → клиент

| Сообщение | Поля |
|---|---|
| `welcome` | `id`, `room` (имя комнаты), `host`, `you`, `rejoined?` (переподключение) |
| `rooms` | `rooms: [{name, mode, count, max, started, host}]` — список комнат |
| `kicked` | `room` — тебя выгнал хост (следом разрыв; причина — до разрыва) |
| `roominfo` | `room`, `mode`, `maxPlayers`, `timeLimit` (мин, 0 = без лимита), `difficulty`, `botsOn`, `count`, `started`, `host` (имя) |
| `players` | `room`, `players: [{id, name, host, ready, cls, team, wantTeam?, bot?}]` |
| `started` | `room`, `mode`, `maxPlayers`, `timeLimit`, `endsAt` (unix-ms дедлайна, 0 = без лимита), `you`?, `youTeam`?, `rejoined?`, `obj` (точки/флаги/бомбы с первого кадра), `players: [{id, name, host, bot?, cls, team, gear?, spawn:{x,y}}]` (боты id<0) |
| `snap` | `id` + поля снапшота — от соседа (боты: id<0, шлёт сервер ~8Гц) |
| `damage` | `room`, `target`, `hp` (остаток), `armor` (остаток), `from`, `zone` (head/body/legs), `w` (оружие) |
| `dead` | `room`, `id`, `by`, `zone`, `w` |
| `spawn` | `room`, `id`, `x`, `y`, `hp`, `armor` (возрождение) |
| `score` | `room`, `blue`, `red`, `limit`, `timeLeft` (сек до конца, -1 = без лимита), `board: [{id, name, kills, dm, d, fl}]` (dm — урон, d — смерти, fl — доставки флага CTF), `seq` (монотонный номер; клиент пока игнорирует, пригодится в v8) |
| `over` | `room`, `winner` (team, id или `'draw'`), `blue`, `red`, `limit`, `board` (те же поля, что в `score`) |
| `obj` | `room`, `mode`, `obj` (точки/флаги/бомбы — по режиму), `seq` (как в `score`) |
| `banner` | `room`, `text`, `color` (событие: захват/доставка/установка), `sfx`? (звук: flag/point/sudden), `team`? (чья команда — клиент маппит свой/чужой сэмпл) |
| `fire` | `id`, `weapon`, `x`, `y`, `angle`, `n` — выстрел соседа (релей людей `tx`/`ty` не ставит; `tx`,`ty` шлют только боты `BOT-<cls>` вместе с точкой прицеливания — клиент дорисует из своего дула в неё; вспышка+трассер+звук, урон отдельно `damage`) |
| `naded` | `id`, `type`, `x`, `y`, `angle` — полёт гранаты |
| `boom` | `id`, `type` (frag), `x`, `y` — взрыв (вспышка+звук; урон считает сервер отдельно `damage`; дым идёт отдельно `smoke`) |
| `smoke` | `id`, `x`, `y` — дым (визуал) |
| `kit` | `id`, `type`, `x`, `y`, `team` — чужой кит |
| `kitok` | `id`, `by` — кит занят (убирать/выдавать) |
| `kitfix` | `from` (старый id), `id` (новый id) — только автору кита (при коллизии id) |
| `pong` | `n` |
| `error` | `msg` |

## Правила

- Комнаты по имени (1–24 символа); `main` — дефолт для LAN. Пустая кастомная
  удаляется, `main` — сбрасывается. Лимит — 20 комнат.
- Первый — хост (корона 👑); хост ушёл до старта — корона следующему.
- Хост выгоняет крестиком (до старта, себя — нельзя): жертва получает `kicked` и разрыв.
- Старт — только когда все готовы (включая хоста): иначе `error` «Ждём готовности: …».
- Переполнение и вход чужого в идущий матч отклоняются в `hello`; своё имя в идущем матче = возврат места (тот же id + `started`+`score`+`obj`+`spawn` лично, мёртвый — мгновенный респаун; висящий старый сокет с тем же id гасится); новичок в первые 60с матча (не DUEL, есть место) входит сразу.
- Ушедший посреди матча тихо выбывает (`dead` с `by: -1`, без очков) — труп-мишень не висит.
- Все люди ушли из матча — место держится 60с, потом сброс (режим TDM, 8 мест, матч стёрт).
- Боты: хост просит `bots` в `start` (0–4, влезть в maxPlayers, баланс команд); id отрицательные, снапы шлёт сервер, урон считают как у людей, в ростере/счёте с `bot:true`. В DUEL ботов нет. Ведут объективы по режиму: KOTH — чужие точки (все наши — держать ближайшую, мост Б берут сверху), CTF/BOMB — носильщик бежит домой/на установку, остальные кроют или догоняют чужого носильщика; в TDM/FFA охотятся на ближайшего. Огонь из классового ствола только по видимым (стены режут).
- Команды: желание `team` до старта (видно всем как `wantTeam`); на старте желания учитываются, конфликт в дуэли — хост синий; авто — через одного.
- Бой: фраги в счёт только в TDM/KOTH/DUEL (в CTF/BOMB очки — только доставка/установка, как в одиночке); лимиты TDM 30, FFA 30, CTF 3, BOMB 3, KOTH 200, DUEL 10. Подбор/возврат/доставка — ступнями (низ тела = y+48, мосты не цепляет). Разминирование как в одиночке: только лежащая чужая бомба, рядом живой враг 5с (отошёл — сброс; несёмую не трогаем).
- ХП/броня по классу (база): Assault 100/40, Tank 150/100, Medic 90/30, Sniper 80/20; свой билд (гены/сеты) едет в `hello`/`cls`/`snap` (`maxHp`/`maxArmor`) и поднимает капы возрождения и китов.
- Броня гасит 60% урона, пока цела; идёт в `damage`/`spawn`/`snap`, сброс на возрождении, аптечка +40 ХП (до своего maxHp), бронекит +30 (до своего maxArmor).
- Зоны попаданий как в одиночке: голова ×2 (+ свой хедшот-множитель 1–2), ноги ×0.7.
- Стойкость жертвы (damageTakenMult: ульта танка 0.3 и т.п.) — из её же снапов (0.2–1), применяется после брони.
- Щит спавна 1с как в одиночке: свежак неуязвим.
- Френдлифаер — фича только онлайна (в одиночке урон по своим игнорит): в командных режимах по своим урон ×0.5 (считается до брони); тимкилл — минус кил и минус урон добивания, минус очко команде — только где фраги в счёт; суицид нейтрален (без очков и зачёта). В FFA своих нет.
- Взрыв гранаты: радиус 195, спад 1−(d/R)×0.55 (на краю ~54), рядом с кидавшим (400px), стены режут по двум точкам, ботов тоже ранит. Френдлифаер тут тоже онлайновый: по своим ×0.5 (тимкилл −1 килл/−урон, суицид нейтрален).
- Стены как в одиночке: пули/нож/взрывы/боты проверяют отрезок по геометрии арены (дальше 1600 — без проверки). Телепорт >600px/с — серверная позиция стоит (вид идёт).
- Переподключение тем же ником гасит старый сокет (угон слота закрыт).
- Время матча ставит хост (`timeLimit`, мин; 0 = без лимита): дедлайн в `started.endsAt`, остаток в `score.timeLeft`, ничья на сирене — овертайм (первое очко/фраг решает), а не `draw`.
- Флаги/бомбы: дроп при смерти, автовозврат (флаг 22с, бомба 15с), подбор сбрасывает таймер. Подбор/возврат/доставка/точки — ступнями (низ тела = y+48, мосты от земли не цепляет). Боты идут по опоре (supportRest), а не по воздуху.
- Боты: стволы — точные статы штатных стволов классов (Assault bad_ak47 17/650, Tank M249 20/720, Medic UZI 12/500, Sniper Winchester 45/950; темп очередей: ствол × cadMult сложности), огонь — как aimPoint в одиночке (упреждение lead, ошибка aimChance/hitChance/промахи 26/42/60, разброс на ходу moveSpread, разброс ствола spreadDeg), попадание — геометрией (голова r11/тело), только по видимым в живую голову (headY из снапов), ведут объективы по режиму. Сложность ставит хост (Новичок 0.32/×0.85/cad×2.2, Бывалый 0.68/×1.05/cad×1.5, Ветеран 0.9+aim0.7/×1.2/cad×1.0); +15% HP ветерана в сети нет (ХП ботов — база класса).
- Проверка попаданий: живой/в матче, урон 1–150, темп пули ≤40/с (дробь — одним хитом), нож ≤4/с, огонь ≤20/с, дистанция пули ≤1300, ножа ≤140, взрыв ≤400 от кидавшего.
- Смерть → возрождение через 5с. Победа → `over`, комната в лобби-режим.
